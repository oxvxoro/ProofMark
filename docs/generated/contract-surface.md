# 생성된 공개 계약 표

> CI가 소스 정의와 비교하는 요약이다. 계약 설명의 유일한 출처가 아니며, 의미 문서는 별도 검토한다.

- 도구 패키지 버전: `0.4.0` (`Version.props`)
- planner 규칙 ID: `P001A`, `P001B`, `P002`, `P003`, `P004`, `P005`, `P006`, `P007`, `P008`, `P009`, `P010`, `P011`
- Proof 이유 코드: `BASE_REF_NOT_FOUND`, `CALLER_POTENTIALLY_TRUNCATED`, `CHANGE_BINARY_ANALYSIS_UNAVAILABLE`, `CHANGE_CAPTURE_CONTENT_HASH_FAILED`, `CHANGE_CAPTURE_UNTRACKED_FAILED`, `CHANGE_DELETION_ANALYSIS_UNAVAILABLE`, `CHANGE_FILE_WIDE_FALLBACK`, `CHANGE_NONEMPTY_PLAN_EMPTY`, `CHANGE_STRUCTURED_DELTA_FAILED`, `CHANGE_SUBMODULE_ANALYSIS_UNAVAILABLE`, `CHANGE_UNSUPPORTED_KIND`, `DISTILL_CONFIG_NOT_FOUND`, `EVIDENCE_KIND_MISMATCH`, `EVIDENCE_SCOPE_MISMATCH`, `EVIDENCE_SOURCE_IDENTITY_MISSING`, `EVIDENCE_STALE_SOURCE`, `EVIDENCE_TOO_WEAK`, `HEURISTIC_EDGE_BLOCKING`, `IMPACT_LOCATION_UNKNOWN`, `IMPACT_POTENTIALLY_TRUNCATED`, `MANUAL_REVIEW_REQUIRED`, `NO_CHANGE`, `REQUIRED_EVIDENCE_CAPABILITY_MISSING`, `REQUIRED_EVIDENCE_FAILED`, `REQUIRED_EVIDENCE_MISSING`, `SOURCE_FRESHNESS_DRIFT`
- Proof MCP 도구: `proof_certificate_verify`, `proof_config_validate`, `proof_explain`, `proof_map_suggest`, `proof_obligations`, `proof_plan`, `proof_summary`, `proof_verify`
- Distill check 필드: `Kind`, `Command`, `Source`, `Timeout`, `StopOnFailure`, `DependsOn`, `Artifact`, `Project`, `Coverage`
