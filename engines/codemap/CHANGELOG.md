# 변경 기록

## 미게시

### 추가

- `CodeMap.Engine` 애플리케이션 계약, 준비 정책, 루트 신선도 서비스, 키 단위 비동기 잠금, 순수 증분 계획 유틸리티.
- 명시적 질의 백엔드 기본 연산, 질의 파사드, SQLite 마이그레이션 원장, 공유 변수 배치.
- 아키텍처, 호환, 벤치마크 기준선, 릴리스 검증 문서.

### 변경

- SQLite 프로젝트 교체가 그래프 트랜잭션과 함께 `updating`에서 `ready`로 넘어간다.
- C# 엣지 신원과 웹 신뢰도/폴백 정책을 분석기 버전을 바꾸지 않고 한곳으로 모았다.

### 수정

- 질의 계층 도우미가 같은 배치와 결정적 순회 규칙을 공유한다.

### 성능

- 벤치마크 등급과 기준선 산출물 형식을 정했다. 안정된 러너 기준선이 생기기 전에는 벽시계 회귀를 경고로 둔다.

### 호환

- 기존 CLI JSON v4/v5, 사용자 정의 LSP v1, 의미 슬라이스 v1, SQLite 스키마 v4 계약은 그대로다.
