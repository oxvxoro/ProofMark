# 호환과 버전

| 표면 | 현재 버전 | 올릴 때 |
| --- | ---: | --- |
| CodeMap 도구 | 0.4.0 | 배포된 CLI 동작이 바뀔 때 |
| SQLite 스키마 | 4 | 지속 테이블, 열, 인코딩이 바뀔 때 |
| C# 분석기 | 7 | 노드, 엣지 의미, ID, 신뢰도, 구문 지원이 바뀔 때 |
| 웹 분석기 | 7 | 웹 노드, 엣지 의미, ID, 신뢰도, 구문 지원이 바뀔 때 |
| CLI 질의 JSON | v4 | v4 계약을 의도적으로 바꿀 때 |
| CLI evidence JSON | v5 | evidence 계약을 의도적으로 바꿀 때 |
| 사용자 정의 LSP JSON 브리지 | v1 | 요청 또는 응답 계약이 바뀔 때 |
| 의미 슬라이스 | v1 | 슬라이스 요청 또는 결과 의미가 바뀔 때 |
| SCIP 임포트 | v1 | 임포트 그래프 또는 제공자 수명 주기가 바뀔 때 |

리팩터링, 파일 이동, 애플리케이션 계층 추출만으로 분석기나 JSON 버전을 올리지 않는다. 분석기 버전이 바뀌면 다시 인덱싱한다. 스키마 변경은 마이그레이션이거나 `codemap index --force`를 명시해야 한다. 분석기 의미 변경은 재인덱스만 필요하며 데이터베이스 마이그레이션이 아니다.

깨지는 릴리스 노트에는 심볼 ID 의미, 노드와 엣지 종류, 신뢰도, 스키마, CLI JSON, MCP 매개변수, 순회 기본값, 소스 우선, 무시 규칙을 적는다.
